# 🌐 HYBRID MARKETPLACE — 9-Tier Enterprise Directory Architecture

| Tier Level | Path / Structure Example | Architectural Role & Description |
| :--- | :--- | :--- |
| **Tier-1 (Project Root)** | `E:\django_python\` (`core/`, `settings/`, `cli/`) | Core project root, central settings, CLI utilities, and main router (`core/urls.py`). |
| **Tier-2 (Apps Container)** | `apps\` | Central directory housing all modular domain apps. |
| **Tier-3 (Group Apps / Domain)** | `apps\catalogs\`, `apps\users\`, `apps\systems\` | Top-level business domains (8 Group Apps) with domain-level `urls.py`. |
| **Tier-4 (Sub-Apps / Components)** | `apps\catalogs\attributes\`, `apps\users\superusers\` | Micro sub-apps and isolated functional components. |
| **Tier-5 (Module Packages)** | `...\views\`, `models\`, `serializers\`, `services\`, `templates\` | Target executable packages synchronized by `sync_init.py`. |
| **Tier-6 (Nested Sub-Packages)** | `...\templates\superusers\`, `...\management\commands\` | Deeply nested sub-folders inside packages or template namespaces. |
| **Tier-7 (Leaf Python Code)** | `...\views\superuser_views.py`, `urls.py` | Leaf `.py` source files containing classes, ViewSets, APIViews, and functions. |
| **Tier-8 (UI & Static Assets)** | `...\templates\superusers\dashboard.html` | HTML templates, static scripts, and UI assets. |
| **Tier-9 (Telemetry & Docs)** | `doc\ARCHITECTURE_TIERS.md`, `logs\sync_init_audit.json` | Documentation and JSON audit trails generated by automation scripts. |
